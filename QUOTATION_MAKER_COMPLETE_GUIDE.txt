QUOTATION MAKER PRO — COMPLETE SETUP GUIDE

FILES
1. index.html — main quotation maker
2. google_sheet_apps_script_v2.gs — Google Sheets backend
3. This guide

GOOGLE SHEET SETUP
1. Create a Google Sheet.
2. Extensions → Apps Script.
3. Delete the default code.
4. Paste google_sheet_apps_script_v2.gs.
5. Save.

DEPLOY
1. Deploy → New deployment.
2. Type: Web app.
3. Execute as: Me.
4. Who has access: Anyone.
5. Deploy and authorize.
6. Copy the URL ending in /exec.

CONNECT HTML
1. Open index.html in Chrome/Edge.
2. Settings → Google Apps Script Web App URL.
3. Paste the /exec URL.
4. Click Test Connection.

GOOGLE SHEETS
The script creates: Quotations and ItemCatalog.
Quotations columns: QuoteNo, Date, Company, Phone, Email, Address, GSTIN, Client, ClientMobile, Validity, Tax, DefaultProfit, Mode, SimpleMode, Notes, Total, ItemsJSON, UpdatedAt.
ItemCatalog columns: ItemName, CostRate, DefaultProfit, UpdatedAt.

SIMPLE QUOTATION MODE
Click “Simple Quotation: OFF” to turn it ON. ON mode hides Rate and item-wise Amount from the client quotation. The final Grand Total remains visible. Turn it OFF for the normal detailed quotation. SimpleMode is saved with the quotation.

DIRECT AMOUNT
Each item has Cost, Profit %, Rate and Amount. If Amount is entered manually, Rate = Amount / Qty and actual Profit % is calculated automatically. If Rate is entered, Amount = Rate × Qty.

ITEM CATALOG
Existing ItemCatalog items appear as browser suggestions when typing an item. Selecting an existing item fills its Cost Rate. New/changed items are synchronized to ItemCatalog when Save + Sheet is used. After manually editing ItemCatalog, refresh the HTML page.

FETCH INVOICE
Fetch Invoice supports search by: quotation/invoice number, Client Name, or Client Mobile Number. Select a result to restore the quotation.

WHATSAPP SHARE
Every fetched result has “Share on WhatsApp”. It opens WhatsApp with a ready message containing client name, quotation number, date, items and Grand Total. For an Indian 10-digit number, 91 is added automatically. This uses wa.me and does not require WhatsApp Business API.

LOGO & COLOR
Settings → Company Logo → Choose File. If no logo is selected, Company Name is displayed. Settings → Invoice Theme Color changes quotation heading, table header and accents.

SAVE / EXPORT
Save + Sheet stores the quotation in Google Sheets and updates ItemCatalog. Download JPEG creates a client-ready image. Print / PDF can be used to save an A4 PDF.

TROUBLESHOOTING
- Use the /exec URL, not /dev.
- Web app must be Execute as Me and access Anyone.
- If Apps Script is changed, update/redeploy the web app version.
- If Fetch finds nothing, first confirm the quotation was saved with Save + Sheet.
- If Item suggestions are empty, confirm ItemCatalog has data and refresh the HTML.
- WhatsApp requires a valid client mobile number.

OLD SHEET NOTE
If you already have the previous Quotations sheet, back it up first. The updated backend adds the SimpleMode column and changes the column layout. A fresh blank Google Sheet is the easiest setup.

SECURITY
Do not store passwords, bank credentials, private API keys or other highly sensitive information in the quotation sheet.

RECOMMENDED WORKFLOW
Create → Add Items → Set Profit or Direct Amount → Simple ON/OFF → Check Preview → Save + Sheet → Download JPEG/PDF → Fetch later by Invoice/Name/Mobile → Share on WhatsApp.
